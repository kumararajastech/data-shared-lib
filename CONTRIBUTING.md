# Contributing to DataSharedLib

Thank you for contributing! Please review the following guidelines before submitting pull requests or issue reports.

## Workflow
1. **Fork / Branch**: Create a feature branch off `main` using `feature/your-feature-name` or `bugfix/issue-description`.
2. **Coding Standards**: Ensure your code strictly follows C# 13 / .NET 10 standards as defined in `.editorconfig` and `AGENTS.md`.
3. **Build & Test**: Build the solution locally and verify zero compiler warnings.
4. **Pull Request**: Submit a Pull Request targeting `main`. Complete all checklist items in `.github/PULL_REQUEST_TEMPLATE.md`.

## Commit Message Format
We follow Conventional Commits:
- `feat: add stored procedure output parameter async streaming`
- `fix: prevent null reference exception in DataTableHelper mapper`
- `docs: update README with bulk copy usage example`
